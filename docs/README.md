# Kartu documentation

These guides explain the console and its tools. The terse, complete reference is
[API.md](../API.md) — the same text `kartu docs` prints and the MCP `docs` tool serves.
The rendered version of everything here lives at <https://niconistal.github.io/kartu/>.
